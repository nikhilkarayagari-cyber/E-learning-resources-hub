**E-Learning Resources Hub**

E-Learning Resources Hub is a web-based platform designed to provide students and learners with an easy way to access educational resources and learn about various subjects. The platform aims to make learning simple, accessible, and convenient by organizing study materials and useful learning resources in one place.

**Features:**
- Easy access to educational resources.
- Organized learning materials for different subjects.
- Simple and user-friendly interface.
- Supports self-paced learning.
- Helps students improve their knowledge and skills.

**Technology:** Frontend Web Technologies, Supabase Backend.

**Goal:** To make online learning easier by providing educational resources in one convenient platform.
